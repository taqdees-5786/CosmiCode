# CosmiCode 🚀
 
A solar system game for learning about planets.
 
---
 
## What is This?
 
A website where students explore planets, learn facts, and answer questions. Built with HTML, CSS, and JavaScript only.
 
---
 
## What You Need
 
- A web browser (Chrome, Firefox, Safari, Edge)
- A text editor (VS Code, Notepad++)
- Git and GitHub account
- Python 3 (to test locally)
 
---
 
## Quick Start
 
1. Clone the repository
2. Create the folder structure
3. Copy the base files
4. Run: `python -m http.server 8000`
5. Open: `http://localhost:8000`
 
---
 
## The Game (6 Chapters)
 
1. Welcome screen with animation
2. Learn about the Sun
3. Explore inner planets (Mercury, Venus, Earth, Mars)
4. Explore outer planets (Jupiter, Saturn, Uranus, Neptune)
5. Challenge game - arrange planets and answer quizzes
6. Show achievements and final score
 
---
 
## How the Team Works
 
Each person makes one chapter:

- Others help and learn as they go
- Copy examples and modify them
- Test in browser
